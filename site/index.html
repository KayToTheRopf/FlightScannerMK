Blockfreie Datenquellen & 3-Stufen-Trust-Architektur (Zero Scraping)

Warum dieses Radar auf GitHub Actions niemals durch IP-Sperren oder Kleinanzeigen-Betrug ausfällt.

01. MyDealz Official RSS & Pepper XML

Liest die offiziellen XML-Feeds für Elektronik, Gaming, LEGO und Uhren inkl. `nextBestPrice` (PVG-Vergleichspreis) und prüft die Community-Temperatur (z.B. ≥ 100°).

02. Steam DE & CheapShark JSON API

Fragt offizielle REST-Endpunkte für digitale PC-Spiele ab (nur autorisierte Stores wie Steam, GOG, Humble) und kombiniert historische Tiefstpreise mit dem Steam-Review-Score.

03. eBay Official Browse REST API

Nutzt OAuth2-Filter statt HTML-Scraping: Nur Sofort-Kaufen, ≥ 98,5 % positive Verkäuferbewertungen und Ausschluss von Zustandscode 7000 (Defekt / Ersatzteile).
